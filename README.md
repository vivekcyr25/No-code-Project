## Deployment

Configured for static export (`output: "export"`) compatible with:
- **GitHub Pages** — push `out/` to `gh-pages` branch
- **Vercel** — auto-detects Next.js, zero config needed

- Server-side API keys only — never committed to repository
- Conventional Commits discipline
